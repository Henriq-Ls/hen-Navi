---
name: Uso de dados móveis
description: Necessidade do usuário de limitar o consumo de internet móvel no hen-Nave.
---

O usuário mora na roça e usa a internet pelo chip do celular; quer reduzir o consumo de créditos móveis.

**Why:** economizar a franquia móvel motivou o pedido de um modo de economia de dados.

**How to apply:** ao projetar recursos de rede para o hen-Nave, priorize evitar downloads desnecessários de imagens e mídia sem desativar JavaScript globalmente ou comprometer funções essenciais.
